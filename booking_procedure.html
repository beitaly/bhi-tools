Step-by-step procedure
  1. 01
    Receive VP confirmation. Note surname, pax, travel dates, product code, and variant (4★ or 4S, 5 or 7 nts).
    Check the Boat Tickets tab in the pivot for any existing entry first.
  2. 02
    Check availability at primary hotels. Start with Pallanza (Maggiore) and Barchetta (Como). For Garda, try Acquaviva or Ziba in the Desenzano/Peschiera area first.
  3. 03
    Reserve hotels via the correct OTA. Record invoice references and batch totals in the pivot DETAILS column (e.g. "in 1622.07").
  4. 04
    Book Navigazione Laghi boat tickets.
    ⚠ Boat Ticket app — DO NOT use in production (Nexi session-bound issue unresolved). Book directly with Navigazione Laghi in an unbroken browser session.
  5. 05
    Book wine tasting via BHI B2B system (manual). Note supplier reference.
  6. 06
    Enter all costs in the 2026 Bookings Pivot (tab: 2026-new). One row per supplier payment. Code = client surname.
  7. 07
    Generate voucher and send to client. Mark voucher_ready = yes in the Boat Tickets tab.
4S vs 4★: The 4S tier uses the same hotel pool and itinerary structure, but only the upper-end properties within each destination have rates loaded for this category. The booking procedure is identical — the difference is which hotels you book, not how you book them. Rates are higher; the pricing chain is the same (netto × 1.06 × 1.23).

Step-by-step procedure
  1. 01
    Receive VP booking. Note client details, travel dates, pax count, and product code.
  2. 02
    Open the Excursion Booking App. Use the VP portal scraper to pre-fill client data if available.
  3. 03
    Search and book each of the 3 Servantrip excursions (Venice, Verona, Padua) individually. Confirm availability for each date.
    Confirm with Concezio whether sandbox or production is active before booking.
  4. 04
    Book wine tasting separately via BHI B2B (manual). Note supplier reference.
  5. 05
    Collect all 4 vouchers. Merge into a single PDF using the /vouchers PDF merge UI in the app.
  6. 06
    Enter all 4 costs in pivot (one row per booking). Send merged PDF voucher to client.
